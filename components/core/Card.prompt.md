One-line: the outlined container for menu items, order summaries and marketing blocks.

```jsx
<Card tone="paper" sticker hoverLift padding="var(--space-5)">…</Card>
```

Tones: `paper` (default white), `board` (black — menu-board panels), `red` (promo/announcement), `sunk` (warm grey, quiet grouping). Never soft-blur a card shadow; use `sticker`.

One-line: a menu row — poster-caps name, lowercase ingredient list, poster-font price.

```jsx
<MenuItem name="The Nashville" price={14} heat={2}
  description="fried chicken sandwich with nashville hot seasoning, bacon, coleslaw, pickles, and comeback sauce" />
<MenuItem name="Waffle Fries" price={5} compact />
```

Descriptions are lowercase, comma-run-on, ingredient-first — never marketing prose. `compact` drops the description for sides/drinks columns. `tone="board"` for black menu-board panels.
